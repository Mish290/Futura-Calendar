# Futura Calendar

A minimalist dark-themed personal calendar and habit tracker designed to set daily goals, track your consistency, and keep you focused on what matters.

## Features

- **Daily Goals & Checklists:** Add, check off, and manage tasks for any selected day.
- **Day Rating System:** Right-click any day to mark it as **Positive**, **Neutral**, or **Negative**.
- **Monthly & Yearly Analytics:** Real-time progress rings and counters tracking your total rated days and success rate.
- **Dual Calendar Mode:** Switch seamlessly between the standard **Gregorian calendar** and a **13-month × 28-day calendar** while keeping your daily tasks synced.
- **Persistent Sidebar Note:** A built-in scratchpad saved automatically in your browser's `localStorage`.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. No external dependencies or server required — all data is stored locally in your browser.
